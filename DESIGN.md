# Lamariva design direction

Source: owner-supplied PRD v1.0, section 12.

Reading this as: a career document workspace for Indonesian and international job seekers, in a restrained professional editorial style, ENERGY 2 / RHYTHM 2 / MOTION 1.

- Light blue identifies the primary action and selected navigation; dark ink keeps text readable.
- Warm neutral work surfaces distinguish the workspace from the white paper being edited.
- Georgia headings echo application letters; system sans-serif controls keep long editing sessions readable without remote font requests.
- Document numbers, compact file rows, and paper proportions repeat a document-specific identity motif.
- A narrow sidebar provides stable navigation; the editor reserves most space for the actual document.
- Dashboard uses a compact count strip, recent-document list, and a profile checklist, rather than decorative feature cards.
- Six-pixel control corners and square document pages distinguish controls from content.
- Shadow appears only under document paper to distinguish a printable page from the work surface.
- Motion is limited to hover/focus feedback; reduced-motion removes transitions.
- Text wordmark is used until the owner supplies a logo. No invented portraits, testimonials, employment data, or audience statistics.
- Navigation follows the PRD. All figures are queried from persisted data.
- Light, dark, and system themes share identical layouts; document pages remain printable white.
