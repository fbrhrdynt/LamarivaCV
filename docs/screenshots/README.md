# Screenshot pengujian

Gambar di folder ini berasal dari aplikasi yang berjalan saat pengujian browser.
Nama, email dan dokumen berawalan QA adalah fixture pengujian. Mereka tidak dibuat
oleh seed produksi dan tidak menunjukkan data pengguna nyata.

Tampilan yang direkam: dashboard terang/gelap, editor mobile, form profil mobile,
dan ringkasan admin. Resolusi serta cakupan pengujian dijelaskan di ../QA.md.
